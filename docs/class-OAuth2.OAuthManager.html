Class: OAuthManager

class OAuthManager implements IOAuthManager { }

Issues signed JWTs and delegates atomic session operations to token storage.

Details

Standard JWT claims coexist with historical session claims. Revocation is immediate only when verification includes storage. HTTP grants, client registration, consent and endpoint transport belong to the calling application.

Method: OAuthManager::init()

public function init(array $parameters): void;

Configures signing, verification, lifetimes and optional collaborators.

Details

Each call replaces all settings. Failed initialization preserves the previous configuration.

Parameters

Name Pass type Value type Default value Description
$parameters by value array<string, mixed>

Supported keys are encryption_algorithm (HS256/384/512 or RS256/384/512), secret_key (raw HMAC bytes), public_key/private_key (local PEM paths), pass_phrase (private-key password), access_token_ttl_minutes (integer or decimal integer string, 1..525600, default 10), refresh_token_ttl_days (same format, 1..3650, default 14), token_storage (ITokenStorage), user_authenticator (IUserAuthenticator), issuer (nonempty string), audience (string or nonempty list of strings), key_id (nonempty string), and verification_keys (map of IDs to encryption_algorithm and secret_key or public_key). Collaborators are optional for offline verification; RSA verification needs no private key. Issuer and audience restrictions are enforced when configured; production callers should configure both.

Returns

void

Publishes validated settings and parsed keys together.

Throws

AuthSystemException

If an unknown or invalid parameter is supplied, a key cannot be loaded, its type or strength is invalid, its public and private parts do not match, or the same key is assigned to different algorithms.
