17:      * Loads a session matching the exact user/client pair and one supplied token.
18:      * Implementations must use constant-time hash comparison and must never return recoverable stored
19:      * bearer tokens.
20:      *
21:      * @param array<string, mixed> &$token_record
22:      * Input: user_id, client_id and exactly one of access_token or refresh_token. Output: the matching
23:      * record with expiry, last_activity, family_id and token hashes; only the supplied raw lookup
24:      * token may remain in the array.
25:      *
26:      * @return void
27:      * Replaces the array only on success; missing records throw.
28:      *
29:      * @throws \OAuth2\MissingParametersException
30:      * If a required lookup value is null or empty.
31:      *
32:      * @throws \OAuth2\InvalidTokenException
33:      * If a value is invalid, a token is unknown, or consumed-token reuse is detected.
34:      *
35:      * @throws \OAuth2\AuthSystemException
36:      * If storage cannot read, validate, lock or persist session state.
37:      *
38:      * @author Oleg Schildt
39:      */
40:     public function loadTokenRecord(array &$token_record): void;

42:     /**
43:      * Atomically replaces the session for one user/client pair after fresh authentication.
44:      * Exactly one active record per pair is permitted. Replacement starts a new family, so replay of
45:      * an older family cannot revoke the newly authenticated session.
46:      *
47:      * @param array<string, mixed> &$token_record
48:      * A record containing nonempty string user_id, client_id, access_token and refresh_token, and
49:      * integer Unix timestamps access_token_expire, refresh_token_expire and last_activity. Raw tokens
50:      * are inputs only: persist SHA-256 hashes, never recoverable bearer credentials. The caller must
51:      * not rely on storage mutating this array.
52:      *
53:      * @return void
54:      * Commits the complete record or preserves the previous session on failure.
55:      *
56:      * @throws \OAuth2\MissingParametersException
57:      * If a required lookup value is null or empty.
58:      *
59:      * @throws \OAuth2\InvalidTokenException
60:      * If a value is invalid, a token is unknown, or consumed-token reuse is detected.
61:      *
62:      * @throws \OAuth2\AuthSystemException
63:      * If storage cannot read, validate, lock or persist session state.
64:      *
65:      * @author Oleg Schildt
66:      */

69:     /**
70:      * Atomically checks and consumes a refresh token and replaces its session.
71:      * The check, expiry test, consumed-token history and replacement must share one transaction or
72:      * lock. Reuse of a consumed token must revoke its active family before throwing. Retain consumed
73:      * hashes at least until their original expiration time. Never combine a separate verify operation
74:      * with an unconditional save.
75:      *
76:      * @param ?string $refresh_token
77:      * The previous refresh token to consume exactly once.
78:      *
79:      * @param array<string, mixed> &$token_record
80:      * A record containing nonempty string user_id, client_id, access_token and refresh_token, and
81:      * integer Unix timestamps access_token_expire, refresh_token_expire and last_activity. Raw tokens
82:      * are inputs only: persist SHA-256 hashes, never recoverable bearer credentials. The caller must
83:      * not rely on storage mutating this array. The user/client pair must match the previous token.
84:      *
85:      * @return void
86:      * Preserves the family ID and commits one replacement.
87:      *
88:      * @throws \OAuth2\MissingParametersException
89:      * If a required lookup value is null or empty.
90:      *
91:      * @throws \OAuth2\InvalidTokenException
92:      * If a value is invalid, a token is unknown, or consumed-token reuse is detected.
93:      *
94:      * @throws \OAuth2\AuthSystemException
95:      * If storage cannot read, validate, lock or persist session state.
96:      *
97:      * @throws \OAuth2\TokenExpiredException
98:      * If the current refresh token has reached its expiration time.
99:      *
100:      * @author Oleg Schildt
101:      */
102:     public function rotateTokenRecord(?string $refresh_token, array &$token_record): void;

104:     /**

108:      *
109:      * @param ?string $refresh_token
110:      * The current token authorizing revocation.
111:      *
112:      * @param ?string $user_id
113:      * The user owning the token and sessions.
114:      *
115:      * @param ?string $client_id
116:      * The client bound to the authorizing token.
117:      *
118:      * @param bool $all_user_sessions
119:      * Whether to delete every session of this user instead of only this user/client pair.
120:      *
121:      * @return void
122:      * Revokes only authorized sessions and preserves all other users.
123:      *
124:      * @throws \OAuth2\MissingParametersException

126:      *
127:      * @throws \OAuth2\InvalidTokenException

130:      * @throws \OAuth2\AuthSystemException
