14:     /**
15:      * Configures signing, verification, lifetimes and optional collaborators.
16:      * Each call replaces all settings. Failed initialization preserves the previous configuration.
17:      *
18:      * @param array<string, mixed> $parameters
19:      * Supported keys are encryption_algorithm (HS256/384/512 or RS256/384/512), secret_key (raw HMAC
20:      * bytes), public_key/private_key (local PEM paths), pass_phrase (private-key password),
21:      * access_token_ttl_minutes (integer or decimal integer string, 1..525600, default 10),
22:      * refresh_token_ttl_days (same format, 1..3650, default 14), token_storage (ITokenStorage),
23:      * user_authenticator (IUserAuthenticator), issuer (nonempty string), audience (string or nonempty
24:      * list of strings), key_id (nonempty string), and verification_keys (map of IDs to
25:      * encryption_algorithm and secret_key or public_key). Collaborators are optional for offline
26:      * verification; RSA verification needs no private key. Issuer and audience restrictions are
27:      * enforced when configured; production callers should configure both.
28:      *
29:      * @return void
30:      * Publishes validated settings and parsed keys together.
31:      *
32:      * @throws \OAuth2\AuthSystemException
33:      * If an unknown or invalid parameter is supplied, a key cannot be loaded, its type or strength is
34:      * invalid, its public and private parts do not match, or the same key is assigned to
35:      * different algorithms.
36:      *
37:      * @author Oleg Schildt
38:      */
39:     public function init(array $parameters): void;
