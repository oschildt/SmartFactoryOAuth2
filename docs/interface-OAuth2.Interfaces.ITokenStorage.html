Interface: ITokenStorage

interface ITokenStorage extends IInitable { }

Defines process-safe session persistence, refresh-token rotation and revocation.

Details

All readers and writers of the same backend must participate in the same locking or transaction protocol. Storage must not contain raw bearer tokens.

Method: ITokenStorage::deleteTokenRecordByKey()

public function deleteTokenRecordByKey(string $key, ?string $value): void;

Atomically revokes sessions by a validated key and exact value.

Details

This low-level administrative operation does not authenticate the caller. Public handlers must use authorized manager methods. Refresh-token lookup also recognizes retained consumed hashes and revokes only their matching family.

Parameters

Name Pass type Value type Default value Description
$key by value string

One of user_id, client_id, access_token or refresh_token. The client_id key is global and requires administrative authorization.
$value by value ?string

The nonempty exact identifier or raw token to hash and compare.

Returns

void

Ignores absent records, making possession-based token revocation idempotent.

Throws

\OAuth2\MissingParametersException

If a required lookup value is null or empty.

\OAuth2\InvalidTokenException

If a value is invalid, a token is unknown, or consumed-token reuse is detected.

\OAuth2\AuthSystemException

If storage cannot read, validate, lock or persist session state.

Method: ITokenStorage::rotateTokenRecord()

public function rotateTokenRecord(?string $refresh_token, array &$token_record): void;

Atomically checks and consumes a refresh token and replaces its session.

Details

The check, expiry test, consumed-token history and replacement must share one transaction or lock. Reuse of a consumed token must revoke its active family before throwing. Retain consumed hashes at least until their original expiration time. Never combine a separate verify operation with an unconditional save.

Parameters

Name Pass type Value type Default value Description
$refresh_token by value ?string

The previous refresh token to consume exactly once.
$token_record by reference array<string, mixed>

A record containing nonempty string user_id, client_id, access_token and refresh_token, and integer Unix timestamps access_token_expire, refresh_token_expire and last_activity. Raw tokens are inputs only: persist SHA-256 hashes, never recoverable bearer credentials. The caller must not rely on storage mutating this array. The user/client pair must match the previous token.

Returns

void

Preserves the family ID and commits one replacement.

Throws

\OAuth2\MissingParametersException

If a required lookup value is null or empty.

\OAuth2\InvalidTokenException

If a value is invalid, a token is unknown, or consumed-token reuse is detected.

\OAuth2\AuthSystemException

If storage cannot read, validate, lock or persist session state.

\OAuth2\TokenExpiredException

If the current refresh token has reached its expiration time.

Method: ITokenStorage::saveTokenRecord()

public function saveTokenRecord(array &$token_record): void;

Atomically replaces the session for one user/client pair after fresh authentication.

Details

Exactly one active record per pair is permitted. Replacement starts a new family, so replay of an older family cannot revoke the newly authenticated session.

Parameters

Name Pass type Value type Default value Description
$token_record by reference array<string, mixed>

A record containing nonempty string user_id, client_id, access_token and refresh_token, and integer Unix timestamps access_token_expire, refresh_token_expire and last_activity. Raw tokens are inputs only: persist SHA-256 hashes, never recoverable bearer credentials. The caller must not rely on storage mutating this array.

Returns

void

Commits the complete record or preserves the previous session on failure.
